## What changed and why

One change, in `convo/review.py` and `convo/prompts.py`: the second check added in v5 now shows the model **both versions side by side**. A is what the learner wrote and B is the proposed fix. It asks which is more correct and natural, and to answer A if they are equally good. The sentence is kept unchanged only if the model clearly picks A.

Why: in v5 the second check asked about the learner's sentence on its own ("is this already correct?"), and the 3B model said yes far too easily. That threw away 3 real corrections (04, 36, 40) and made v5 worse than v4.

## Regression check (new)

`scripts/compare_versions.py` reads the raw tune files and marks which versions got each sentence right:

```
id   v1  v2  v3  v4  v5  v6  sentence
```

v1's 04 is marked wrong because its file was scored before 你们有茶吗？ was added to the answer key.

It then compares the new version with the best earlier one and fails (exit code 1) if the new version gets any sentence wrong that the best one got right. v4 and v5 both fail this check; v6 passes. Only 27 (我要买单) is still right in an earlier version (v3) and wrong in v6.

## What I'd change next, and why

v6 is the best version on the tune split (8/10) and the recommended candidate for the final test run, if Ethan agrees. Remaining tune failures:
- **08 我喝咖啡在家** (word order): no version since v1 fixes the place phrase 在家 before the verb; the model keeps rewriting the verb instead.
- **27 我要买单** (correct): the model "fixes" it to 我要付钱, and the A/B check accepts that because both sound fine to it.
- **Explanations:** still half in Chinese.

With more versions, the next change would be a code check that asks again when an explanation is mostly Chinese, then a worked example of moving a place phrase (在…) before the verb. Caveat: the tune split is only 10 sentences, so the 32-sentence test split will be the real measure.
